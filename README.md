# 🚀 Overview

**ERP Inventory Management System** is a complete enterprise-style web application that manages inventory, warehouses, purchasing, sales, suppliers, customers, and stock movement.

The project demonstrates:

- Enterprise business workflow implementation
- Secure Authentication & Authorization
- Inventory lifecycle management
- Warehouse operations
- Purchase & Sales processing
- Scalable architecture using Repository Pattern & Unit of Work

The system is designed following software engineering best practices to simulate a real ERP solution.

# ⚙️ Installation

```bash
git clone https://github.com/ahmedsaeeddev5-alt/ERP-Inventory-System-ASP.NET-Core-MVC.git

cd ERP-Inventory-System-ASP.NET-Core-MVC
```

Restore packages

```bash
dotnet restore
```

Update database

```bash
dotnet ef database update
```

Run project

```bash
dotnet run
```
